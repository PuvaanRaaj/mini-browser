Version 2.0.0

Unreleased · Chromium rewrite

Standalone Chromium core

  • Pinned Chromium 152.0.7977.54 to an exact revision with deterministic macOS and Windows bootstrap, sync, GN, and build tooling.
  • Added seven-run release gates for startup, navigation, ten-tab RAM, idle CPU, controlled energy use, compatibility, and security.
  • Extended the clean-profile market benchmark for direct Minimal Chromium, Chrome, and Firefox comparisons.
  • Kept Electron 1.x as the fallback until 2.x passes profile migration, authentication, signing, update, and rollback tests.

Security, Google authentication, passkeys, and vault

  • Hardened IPC sender checks, renderer sandboxing, navigation, permissions, sessions, and external URL handling.
  • Added system-browser OAuth/PKCE for Minimal-owned Google integrations; embedded Electron Google website login is not claimed as supported.
  • Added WebAuthn account selection and the macOS platform-authenticator path, with Windows Hello and roaming security keys in the cross-platform plan.
  • Moved passwords and TOTP secrets to an asynchronous OS-encrypted main-process vault and migrated legacy authenticator entries.
  • Added local active-page QR capture for Authenticator with drag selection, account review, and ephemeral image handling.

Performance and reliability

  • Added cold/warm startup, first-navigation, ten-tab memory, and idle CPU benchmarks.
  • Prevented malformed block rules from cancelling main-frame navigation and corrected Vercel and renderer type-check failures.
  • Shelved the Rust/native-shell experiment in favour of the complete Chromium browser distribution.

Browser experience

  • Introduced the Minimal name, ring icon, chromeless window, compact address bar, focus mode, keyboard navigation, and animated start page.
  • Added side tabs, hover-expandable icon rail, drag reordering, favicons, favorites and editing, per-site zoom, and session settings.
  • Added navigation, new-tab, focus, shield, password, authenticator, and settings controls plus the full dark palette and optional animated toolbar cats.

Privacy and authentication

  • Added EasyList/EasyPrivacy blocking, a built-in host blocklist, TOTP authenticator, and portable JSON or otpauth:// backup import.
  • Made sessions ephemeral by default and added an explicit, off-by-default “Stay signed in” setting.

Stability, packaging, and website

  • Fixed WebContentsView shutdown crashes, dead tabs, WSL2 blocklist failures, favicon sizing, and navigation errors.
  • Added bundle budgets, lazy loading, cached blocklists, diagnostics, macOS and Windows packaging, release automation, Vercel deployment, SEO, and platform-aware downloads.
  • Published the project under Apache-2.0 with contributor and roadmap documentation.
